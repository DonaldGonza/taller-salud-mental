# Árboles de decisión: base Taller

Informe interactivo de resultados agregados sobre síntomas depresivos, ansiedad y bienestar psicológico.

El sitio incluye tres árboles exploratorios, tablas de grupos y comparaciones descriptivas. Los resultados no establecen causalidad, diagnósticos ni cambios futuros. El método y las fuentes pueden consultarse en el informe.

La publicación contiene únicamente el HTML y tres diagramas PDF. Las bases individuales y los identificadores no forman parte del repositorio.

Para GitHub Pages: publicar la rama `main` desde la carpeta raíz.
